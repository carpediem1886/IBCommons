# IBCommons

A free, open-source questionbank and revision platform for IB MYP and DP students, starting with Physics.

> IBCommons is a student-built, open-source project. It is not affiliated with or endorsed by the International Baccalaureate Organization.

## What students can do

1. **Log in** and choose their programme (MYP or DP).
2. **Paper Generator.** Choose topics and sub-topics, a paper type, SL or HL, and a length (marks or number of questions). Then download the paper and its markscheme as PDFs.
3. **Open Study.** See every question for a topic or sub-topic, type an answer, and have it checked:
   - multiple-choice and numerical answers are checked instantly in the browser;
   - written answers are marked against the markscheme by AI;
   - an **AI tutor** guides the student step by step with questions, without giving the answer away.
4. **Topic Revision.** Step-by-step visual lessons per sub-topic, with quick checks, ending in practice questions.

## How it is built

- A static site: plain HTML, CSS and JavaScript with **no build step**. It can be hosted free on GitHub Pages, Netlify or Vercel.
- **Content is plain JSON** in [`content/`](content/). See [CONTENT_GUIDE.md](CONTENT_GUIDE.md).
- **Supabase** (free tier) provides accounts and runs the AI backend ([`supabase/functions/ai`](supabase/functions/ai/index.ts)). The AI uses Claude through the Anthropic API. The API key stays secret on Supabase and never reaches the browser.
- **Demo mode:** until Supabase is connected, the site works with browser-only accounts and the AI features switched off.

```
index.html               the app shell
assets/css/style.css     styles (brand colours and fonts)
assets/js/               app.js (routes) · auth.js · generator.js · study.js · revision.js · pdf.js · ai.js
assets/brand/            logos, favicons, fonts (from the IBCommons brand kit)
content/<subject>/<programme>/
    syllabus.json        topics, sub-topics, paper types
    questions/<code>.json questions for one sub-topic, e.g. A.2.json
    revision/<code>.json  the revision lesson for one sub-topic
    index.json           generated by tools/build_index.py; do not edit by hand
supabase/                AI Edge Function and database migration
tools/build_index.py     checks content and rebuilds index.json files
```

## Run it on your computer

You need Python 3, which is already on macOS.

```bash
python3 -m http.server 8080
```

Then open <http://localhost:8080>. After adding or changing content, run:

```bash
python3 tools/build_index.py
```

## Connect Supabase (accounts + AI)

1. Create a free project at [supabase.com](https://supabase.com).
2. In **Project Settings → API**, copy the *Project URL* and the *anon public* key into [`assets/js/config.js`](assets/js/config.js). The anon key is meant to be public.
3. In **Authentication → URL Configuration**, set the *Site URL* to your published address (for example `https://<you>.github.io/IBCommons/`).
4. Optional: enable Google sign-in under **Authentication → Providers**, then set `GOOGLE_SIGN_IN: true` in `config.js`.
5. In the **SQL editor**, run [`supabase/migrations/20261120000000_ai_usage.sql`](supabase/migrations/20261120000000_ai_usage.sql). It creates the per-student daily AI limit.
6. Deploy the AI function with the [Supabase CLI](https://supabase.com/docs/guides/cli):

   ```bash
   supabase login
   supabase link --project-ref <your-project-ref>
   supabase secrets set ANTHROPIC_API_KEY=<your key from console.anthropic.com>
   supabase secrets set AI_DAILY_LIMIT=60
   supabase functions deploy ai
   ```

**Cost:** the AI uses `claude-opus-5-5` (set in `supabase/functions/ai/index.ts`). Each tutor reply or marked answer costs roughly one to two US cents. `AI_DAILY_LIMIT` caps how many requests each student can make per day. Set a monthly spend limit in the Anthropic Console as well.

## Publish on GitHub Pages

1. Create a GitHub repository (for example `IBCommons`) and push this folder to it.
2. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, then `main` and `/ (root)`.
3. The site appears at `https://<your-username>.github.io/IBCommons/`. Update `REPO_URL` in `config.js` and the Site URL in Supabase.
